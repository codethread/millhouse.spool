# Repository automatic delivery

The consolidated source repository has one [Millhouse automatic delivery policy](../auto-run.md). That document and the live workspace own defaults, quality gates, worker/finisher custody, and recovery. Do not copy the retired standalone Codethread workspace policy into packages.

The reusable [agent blocker contract](auto-run.md#agent-blocker-contract) remains shared guidance. Other repositories select their own admission and delivery policy; neither this document nor a package dependency opts cards into execution.
